PROJ-9999: Prevent duplicate profile saves

Ticket Attachment (`agent-view/attachments/PROJ-9999/`)

Requirements

  • Ignore second Save click while first PUT /api/v1/profile request is pending.
  • Disable Save button and show Saving... label during request.
  • Keep server error banner and re-enable Save after a failed request.

Acceptance Criteria

  • Rapid double-click on Save sends exactly one PUT /api/v1/profile call.
  • Save button disabled while isSaving true.
  • Request failure restores Save enabled state and shows server error message.
